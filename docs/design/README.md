## Definition of Done (every step)

- [ ] OOP/SOLID (Protocols, frozen dataclasses, dependency injection); `make check` green
- [ ] Tests cover the happy path **and** the error paths
- [ ] Security: input validated at the boundary, no secrets in code or logs, no `eval`/`pickle`
      on untrusted data, timeouts on network calls, bounded queues and memory
- [ ] Performance: no obvious hot-path waste; measurements recorded (optimisation waits for the
      phase perf review)
- [ ] Design doc updated, with a diagram wherever a component, flow, state or data layout is involved
- [ ] Figures for any data or result, generated by a script into `docs/figures/`

## End of every phase

1. **Perf review**: measure against the phase budget, fix the top bottleneck, record before/after.
2. **Security step** where the phase adds attack surface; keep `security.md` current.
3. **Write-up** in `docs/phases/phaseN.md`: what was built, diagrams, figures, numbers, decisions,
   open questions.
