# Changelog

All notable changes to pitwall. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html): one minor version per
phase, patches in between. How a release is made: [docs/design/dev-pipeline.md](docs/design/dev-pipeline.md#releases).

## [Unreleased]

### Added
- `pitwall.replay`: one race as compact JSON for the browser replay (`RaceReplay`). Every car's
  on-track positions at the full ~4 Hz as delta-encoded integer columns, plus drivers, team colours
  with readable ink, and the track outline. `make export` writes Monza 2024 to
  `frontend/public/races/monza-2024.json`: 20 cars, 353,980 samples, 4.08 MB (1.27 MB gzipped).
  Format: [docs/design/replay.md](docs/design/replay.md).
- `PacedTransport` (requests spaced apart) and `pitwall.files.write_atomic`, shared by the cache
  and the export.
- `docs/design/track.md`: OpenF1's axes, a sample, "no fix" at `(0, 0)` and the distance maths,
  worked through on real data, with a new figure (`track_axes.png`).

### Changed
- Team colours are checked when a driver row is parsed: 6 hex digits, upper case, with a `#` or
  spaces removed. Anything else counts as no colour (grey), instead of reaching the code unchecked.

## [0.1.0] - 2026-11-04

Phase 0: setup, and a first look at the data. Write-up: [docs/phases/phase0.md](https://github.com/Ekanth-Sai/pitwall/blob/v0.1.0/docs/phases/phase0.md).

### Added
- `pitwall.ingest`: a typed OpenF1 client (`OpenF1Client`) over swappable transports, an HTTP
  transport with timeouts and an on-disk cache that keeps successful responses only. Filter names
  are checked before any request, and rows are parsed into frozen dataclasses (`Session`, `Driver`,
  `Lap`, `LocationSample`) or rejected with `SchemaError`.
- Location data fetched in 10-minute chunks, padded and de-duplicated so no sample is lost or
  repeated at a chunk boundary.
- `pitwall.track`: the circuit outline from one representative racing lap (arc-length resampling
  to 500 points, light smoothing), the pit lane from a pit stop's in-lap and out-lap, and the
  rotation that lays the track out landscape. `TrackOutline` serialises to versioned JSON
  (about 10 KB for Monza).
- `LoopIndex`: a grid index for nearest-point queries on the circuit. `TrackOutline.build` is about
  16× faster with byte-identical output.
- `EndpointProfile` and an endpoint survey of seven more OpenF1 endpoints: update rates, nulls,
  units and the measured rate limit (`docs/design/openf1-data.md`).
- Figures generated by `make figures`: the outline, the pit lane, endpoint update rates, the whole
  field at one moment, and every car's gap to the leader.
- Tooling: uv, ruff (with bandit rules), mypy strict, pytest with hypothesis and a coverage gate,
  pre-commit, GitHub Actions CI, and a release workflow that builds, checks and publishes on
  `v*` tags.

### Security
- CI with a read-only token, pip-audit on every PR and weekly, Dependabot, CodeQL, and secret
  scanning with push protection.
- Release artifacts carry signed build provenance (GitHub artifact attestations).
